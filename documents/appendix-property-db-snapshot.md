# Appendix — Current `property_db` snapshot

This is the as-is PostgreSQL catalog captured during project planning. It is **not** the frozen target schema.

Target schema: [03-database.md](03-database.md)  
Source notes: [blockchain.md](blockchain.md)

Known gaps versus the frozen model:

- Missing `risk_assessments`, `risk_indicators`, `transaction_features`, `query_retrievals`, `agent_runs`
- `query_logs.retrieved_transaction_ids` is comma-separated text
- `users.name` should become `full_name`; `users.contact` should become `phone_number`
- `products` is unrelated and should be removed or isolated
- `staging_*` tables must stay out of the application layer
- Core tables still contain derived calendar columns (`year`, `month`, `quarter`, `day_of_week`) that belong in analytics if kept
